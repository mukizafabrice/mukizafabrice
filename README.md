## About Me

I'm a full stack developer from Kigali, Rwanda, with a strong interest in system development and digital design. I enjoy building clean, responsive interfaces and turning complicated requirements into something people can actually use without a manual.

Most of my work is on business systems: multi-role platforms with the kind of logic that has to be right the first time, since a broken workflow is somebody's afternoon. I care as much about the data model and the permissions behind a feature as I do about the screen in front of it, because in this kind of software the edge cases are the job.

On the web I build with React on the front end and Laravel, Express, or Frappe behind it, depending on what the project calls for. Day to day I write Python and PHP on the server and JavaScript and TypeScript on the client, and I'm comfortable moving between them. I'm extending that into mobile with React Native, and finishing a BSc in Computer Science through the University of the People.

You can see more of my work at [fabrice250.netlify.app](https://fabrice250.netlify.app/), and reach me at mukizafabrice18@gmail.com.
